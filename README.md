# AcaGrade: Automated GPA Generator 🎓



## Description

AcaGrade is a Python-based GUI application designed to help university students automate the calculation of their Semester Grade Point Average (GPA). It removes the need for manual calculations by using weighted averages based on credit hours.



## Key Features

-  Graphical User Interface (GUI): Built with Python's Tkinter library.

-  Dynamic Entry: Add unlimited subjects for a single semester.

-  Automated Logic: Calculates GPA based on the formula: `(Sum of Grade * Credit Hours) / Total Credits`.

-  Validation: Prevents incorrect data entry (e.g., negative grades).



## Technology Stack

- Language: Python 3.x

- Libraries:

  - `Tkinter`: For the window and interactive elements.

  - `Messagebox`: For error handling and user alerts.



## How to Run

1. Ensure Python is installed on your system.

2. Run the script: `python grade_generator.py`.

3. Enter subject details and click "Add Subject".

4. Click "Calculate GPA" for the final result.
